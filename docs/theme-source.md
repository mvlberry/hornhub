# Theme source

The site uses the existing [Hugo Ivy](https://github.com/yihui/hugo-ivy) submodule and adapts the reading-column appearance of [Elizen](https://elizen.me/), inspected on 2026-10-19.

- Elizen's [Ivy theme metadata](https://github.com/elizen/elizen-blog/blob/master/themes/ivy/theme.toml) identifies the theme as **Unlicense** and credits Ivy.
- `assets/css/custom.css` contains the reading-column and hybrid-homepage portions of Elizen's public `css/custom.css`, with a Chinese font fallback added. Site-specific comments, catalogs and personal data are excluded.
- `assets/css/site.css` integrates the design with this site's templates, responsive navigation, empty states, archives and Markdown typography.
- Project-level `layouts/` overrides make homepage text configurable and support current Hugo. The base theme submodule is unchanged.

No Elizen articles, personal photos, analytics identifiers or comment-service accounts are included. Google Fonts supplies the original Inter / Noto Serif SC pairing using `display=swap`; local font fallbacks keep the site readable if it is unavailable. Code highlighting is generated by Hugo without a browser-side CDN dependency.
